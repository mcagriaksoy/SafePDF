FAQ

Häufige Fragen

Ist SafePDF kostenlos?

Ja. Die Desktop-App ist kostenlos und Open Source unter GPL-3.0. Pro ist optional und ergänzt Stapelverarbeitung und prioritären Support.

Werden meine Dateien hochgeladen?

Nein. Alles wird auf Ihrem Gerät verarbeitet. Es gibt keinen Cloud-Schritt.

Welche Betriebssysteme werden unterstützt?

Windows, macOS und Linux. Sie können es auch per pip install SafePDF aus PyPI installieren.

Braucht es eine Internetverbindung?

Nein. Ziehen Sie das Kabel ab - es funktioniert weiter. Internet wird nur für optionale Update-Prüfungen genutzt.

Ist es wirklich Open Source?

Ja. Der vollständige Quellcode ist auf GitHub; Sie können ihn prüfen oder selbst bauen.

Kann ich es beruflich nutzen?

Ja. Die GPL-3.0-Lizenz erlaubt kommerzielle Nutzung. Pro ergänzt Stapelverarbeitung für größere Arbeitsabläufe.
